## How to verify the rest

For each unverified species, check the accepted name and classification (GBIF Backbone, Catalogue of Life, Plants of the World Online, FishBase, The Reptile Database, ASM Mammal Diversity Database, BirdLife DataZone) and the Red List category (iucnredlist.org), then add an entry to `src/data/species/verification.json` with the URLs. The unit test `species.test.ts` refuses a record marked verified without a source.
